## 범위와 출처

기준 자료 「자동차AX_명진숙.pptx」, 교수 교재·전사문·강의 메모와 실습 결과를 바탕으로 정리했습니다. [교수님 강의자료 저장소](https://github.com/keerhee/kma-auto-genai-3-1)를 함께 참고하세요. 5~6일차는 포함하지 않습니다.

보충 실습실의 EV 업로드·필터·보고서 다운로드, 가상 CS 규칙 12건, 절감액 계산을 확인했습니다. 가상 CS 규칙 시연은 실제 RAG·LLM 정확도 평가가 아닙니다. 기존 HTML 중 일부 AI 기능은 외부 실행 환경 연결이 필요합니다.

원자료의 권리는 각 권리자에게 있습니다. 재사용·재배포 시 원자료 이용 조건을 확인하세요. 이 저장소에 별도 오픈소스 라이선스를 부여하지 않았습니다.
